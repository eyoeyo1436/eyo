# Project instructions

This repository bundles the [Superpowers](https://github.com/obra/superpowers) skills (MIT, (c) Jesse Vincent; upstream commit 22f0b46)
in `.claude/skills/`.

At the start of every task, read and follow `.claude/skills/using-superpowers/SKILL.md`.
It explains how to find and use the other skills (brainstorming, writing-plans, executing-plans,
test-driven-development, systematic-debugging, verification-before-completion, and others).
